# El-Gamal Digital Signature System

Учебная реализация схемы электронной цифровой подписи Эль-Гамаля, написанная полностью на чистом Python без использования сторонних криптографических библиотек. Проект демонстрирует принципы работы асимметричной криптографии, хэширования и симметричного шифрования на низком уровне.

* **Схема Эль-Гамаля:** Генерация ключей, создание и проверка цифровой подписи.
* **Генерация простых чисел:** Использование теста Миллера-Рабина для поиска безопасных простых чисел вида $p = 2q + 1$.
* **Кастомный ГПСЧ:** Линейный конгруэнтный генератор для создания случайных значений.
* **SHA-256:** Собственная реализация алгоритма безопасного хэширования для получения дайджеста сообщения перед подписью.
* **AES-256:** Самописный блочный шифр (14 раундов, дополнение PKCS#7). Применяется для безопасного хранения закрытого ключа (шифрование ключа паролем пользователя при сохранении на диск).

## Структура проекта

* `main.py` — Точка входа, реализующая интерактивное консольное меню для пользователя.
* `elgamal.py` — Основная логика ЭЦП (классы `ElGamalKeys` и `ElGamalSigner`), а также логика сохранения/загрузки ключей в формате JSON.
* `aes256.py` — Логика симметричного шифрования (S-Box, расширение ключа, раундовые преобразования).
* `sha256.py` — Хэш-функция, принимающая байты и возвращающая 32-байтовый хэш.
* `utility.py` — Математический аппарат: поиск генератора группы, расширенный алгоритм Евклида для поиска обратного по модулю, генерация больших простых чисел.

Проект использует только стандартную библиотеку Python.
